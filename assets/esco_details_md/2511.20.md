Description
Data engineers develop the architecture needed to process, manage, and store large
amounts of data which will be used by data scientists for analysis. They design the
infrastructure and maintain data pipelines and warehouses to leverage data for strategic
advantage.
Scope note
Excludes data scientist and data analyst.
