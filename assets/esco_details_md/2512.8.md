Description
Cloud software developers create, deploy, and modernize software applications to run on
the cloud using microservices, containers, and serverless technologies. They develop
scalable and highly available applications using cloud architectures and best practices.
They incorporate logging and monitoring into their code and are able to perform root
cause analysis on failures.
