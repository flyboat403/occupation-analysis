Description
Miniature set designers design and build miniature props and sets of motion pictures. They
build models used for visual effects that meet the look and requirements of the production.
Miniature set designers cut material using hand tools to construct three-dimensional props
and sets.
Scope note
Includes people producing props for broadcasting programs.
