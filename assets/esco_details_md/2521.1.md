Description
Database administrators test, implement and administer computer databases. They use
their expertise in database management systems to plan, coordinate and implement
security measures to safeguard computer databases. They also use scripts and
configuration files to tailor a database to users' needs.
Scope note
Includes people performing managerial activities.
